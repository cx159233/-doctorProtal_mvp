## 一、患者一屏看系统埋点

### 1.1 埋点事件类型汇总（共12个事件）

## 二、跨院调阅系统埋点改造

### 2.1 改造说明

跨院调阅系统现有埋点**不需要改动事件定义和字段结构**，仅需在所有现有埋点事件的extension中新增一个字段，用于区分调阅来源渠道。

### 2.2 新增字段

| 字段英文名 | 字段中文名 | 字段类型 | 取值说明 | 示例值 |
|-----------|-----------|---------|---------|--------|
| 渠道字段标识 | - | String | 用于区分患者一屏看渠道，具体字段名由开发确定 | - |

### 2.3 需要改造的埋点事件

以下跨院调阅系统事件的extension中需新增渠道字段标识：

**前端埋点（23个事件）**：

## 三、患者一屏看完整埋点链路

### 3.1 标准流程（首次进入，未授权）

```
1. 医生从HIS进入患者一屏看
   onepage.page_enter

2. 系统检查患者未授权，授权弹窗加载完成
   onepage.authorize_loading_success
   (auth_method: 2,3)

3. 医生选择授权方式，授权成功
   onepage.authorize_success
   (authorize_type: 2 / 3)

4. 授权成功后自动进入个人医保画像
   onepage.portrait_view
   (is_authorized: 1)

5. 医生在个人医保画像内交互（可选）
   - 点击全景健康视图卡片
     onepage.portrait_view_card_click (service_type: outpatient)
   - 点击全生命周期时间轴视图列表项
     onepage.portrait_view_timeline_click (service_type: outpatient)
   - 点击全生命周期时间轴视图「查看更多」
     onepage.portrait_view_timeline_more (service_type: national_pacs)
   - 点击智能服务「查看更多」
     onepage.portrait_view_service_more
   - 切换医保信息档案tab
     onepage.portrait_view_insurance_tab_click (insurance_tab: insur / nursing / commercial)

6. 医生进入医保健康档案（可选）
   onepage.health_view

7. 医生在医保健康档案下切换页签（可选）
   onepage.health_view_tab_click
   (service_type: national_pacs)

8. 进入跨院调阅流程（携带渠道字段标识区分渠道）
   → 后续影像/检验调阅埋点同跨院调阅系统（均携带渠道字段标识）
```

### 3.2 已授权流程（同一患者再次进入）

```
1. 医生从HIS进入患者一屏看
   onepage.page_enter

2. 系统检查患者已授权，直接进入个人医保画像
   onepage.portrait_view
   (is_authorized: 1)

3. 后续操作同标准流程第5步起
```
